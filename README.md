# Healthcare-Analysis-Dashboard

# Overview
This project provides an in-depth analysis of healthcare billing, patient data, and hospital services using Power BI. The dashboard delivers a comprehensive view of key financial metrics, treatment costs, and patient care trends, empowering healthcare providers to make data-driven decisions for improved outcomes and resource management.

# Project Goal
The goal of this project is to create an interactive and data-rich dashboard that offers insights into the financial performance of healthcare services. By utilizing advanced data modeling techniques and interactive visualizations, this project helps healthcare professionals, financial analysts, and stakeholders better understand key cost metrics and optimize resource allocation.

# Key Features
* **Data Models**: Structured data modeling that improves data accuracy for effective analysis of billing and treatment costs.
* **Interactive Dashboards**: Enables users to filter data based on department, procedure type, diagnosis, and more to explore detailed insights.
* **DAX Formulas**: Used to create meaningful calculations like average costs and total billing, enhancing the depth of analysis.

# Dashboard Highlights
# Overview
* **Total Billing Amount**: $3M, with detailed breakdowns of treatment costs, medication expenses, insurance coverage, and out-of-pocket payments.
* **Key Financial Metrics**:
  * **Average Billing per Visit: $674.86**
  * **Average Medication Cost: $109.21**
  * **Average Treatment Cost: $526.08**
  * **Room Charges: $36.12**

# Billing Analysis:
 * **Procedure Breakdown**: Total billing by procedures like X-ray ($1.05M), CT Scan ($805,508), MRI ($600,739), and more.
 * **Diagnosis Breakdown**: Analysis of top diagnoses such as Hypertension, Asthma, and Fractures, and their contribution to total billing.
 * **Service Type Breakdown**: Evaluation of billing by service type (Emergency, Inpatient, Outpatient) to identify cost drivers.

# Department Analysis:
* **Top Departments by Billing:**
   * **Cardiology: 25.24%**
   * **General Surgery: 23.34%**
   * **Orthopedics: 24.23%**
* **Patient Visit Trends**: Visualizes inpatient and outpatient trends, including average stay duration and total visits by weekday.

# Patient Data Insights:
* **Outpatient Analysis by Department**: Compares outpatient visits across departments such as Cardiology, General Surgery, Orthopedics, and Neurology.
* **Doctor Performance**: Features average ratings of doctors to provide a qualitative aspect of patient care.

# Doctor Performance:
* **Average ratings**: Dr. Chris Evans (5.45), Dr. Emma Jones (4.85), Dr. Johnson Grek (5.05).

# Technologies Used
* **Power BI**: For data visualization and dashboard creation.
* **DAX (Data Analysis Expressions)**: Used to create custom calculations for key performance metrics.
* **Power Query**: Used for data transformation and cleaning.
